# Портфолио — публичная витрина

Самостоятельный статический сайт для GitHub Pages. В комплект входят главная страница, пять интерактивных демо, их стили, скрипты и демонстрационные данные. Python-сервер, пароли, базы заявок и Tkinter сюда не входят.

## Посмотреть локально

Откройте терминал в этой папке:

```sh
python -m http.server 8000
```

Перейдите на http://localhost:8000/. Не открывайте HTML двойным щелчком: демо загружают JSON через HTTP.

## Опубликовать через GitHub Desktop

1. В GitHub Desktop: **File → Add local repository**, выберите именно папку `portfolio-github`.
2. Если репозитория ещё нет, нажмите **create a repository here**. Убедитесь, что корень репозитория — эта папка, в которой лежит `index.html`.
3. Просмотрите Changes, затем **Commit to main** с описанием `Publish portfolio`.
4. **Publish repository** → имя, например `web-portfolio` → отключите **Keep this code private**, если хотите общедоступный репозиторий.
5. На github.com: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
6. Дождитесь успешной публикации. Адрес будет показан в разделе Pages: `https://ВАШ-ЛОГИН.github.io/web-portfolio/`.
7. Откройте главную и все пять кейсов. Дашборд не требует логина или пароля.

Папку можно назвать иначе. Ссылки относительные и работают в подпапке GitHub Pages. Коммиты и отправку выполняет владелец через Desktop; в подготовленной папке история Git не создана.

## Возможности и ограничения

- Дашборд: графики, фильтры, сортировка, CSV, две темы; серверное управление отключено.
- Магазин и checkout: демонстрационное оформление, корзина хранится в браузере. Деньги не списываются.
- Школа и репетитор: формы проверяют поля, но не отправляют реальные заявки.
- Вымышленные бренды и данные. Коммерческие результаты не заявляются.
- Фотографии косметики и некоторые шрифты исходных кейсов загружаются с внешних сервисов и требуют интернета.

Главная: `index.html`, оформление: `assets/styles.css`. Серверная версия остаётся в соседней рабочей папке `портфолио` и развивается отдельно. Изменения в ней не копируются в эту папку автоматически.
