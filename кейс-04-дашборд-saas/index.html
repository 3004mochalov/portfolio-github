Как посмотреть кейс · короткий гайд

Быстрый просмотр без пароля. Если видите форму входа, нажмите «Посмотреть демо без входа» над ней. На GitHub Pages демо открывается автоматически. Можно переключать темы, смотреть графики, фильтровать таблицу и скачивать CSV. Для перехода к авторизации нажмите «Войти для управления». Демо не изменяет серверные данные.

Полная версия на компьютере. В общей папке портфолио один раз запустите setup.bat и создайте администратора. Затем запустите start-server.bat, откройте http://127.0.0.1:8080/ и выберите кейс 04. Войдите с почтой и паролем, указанными при настройке. Общего готового пароля нет; на размещённом сервере доступ выдаёт его владелец.

  1. Обзор: посмотрите показатели, выручку и воронку. MRR — ежемесячная повторяющаяся выручка активных подписок. Выбор «3 / 6 месяцев» меняет только график выручки.
  2. Клиенты: введите название, выберите статус и сортировку. «Выгрузить CSV» скачает текущую отфильтрованную таблицу — её можно открыть в Excel.
  3. Тема: кнопка в боковой панели переключает светлое и тёмное оформление.
  4. Пользователи и настройки: на сервере администратор создаёт учётные записи, отключает доступ, меняет название пространства и цель выручки. Аналитик просматривает данные и выгружает CSV.

Изменить графики и клиентов: запустите start-admin.bat, подключитесь к серверу, выберите «Metric — SaaS». После редактирования нажмите «Применить значение локально», затем «Опубликовать изменения на сервер» и обновите дашборд.

Все числа учебные. Для локального просмотра используйте HTTP-сервер: открытие index.html двойным щелчком не подходит для загрузки данных.
